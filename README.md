# Academic Projects

This repository collects selected mathematics projects, presentation materials, teaching documents, and resume materials.

## Projects

### Product Measure for Fubini and Tonelli Theorems

An annotated project on product sigma-algebras, product measures, Tonelli's theorem, Fubini's theorem, examples, and proof explanations.

File:
- `projects/Product_Measure_Fubini_Tonelli_Project.pdf`

### Multivariable Taylor Theorem

A multivariable analysis project explaining directional derivatives, the multivariable Taylor theorem, reduction to one variable, examples, error estimates, and applications.

Files:
- `projects/Multivariable_Taylor_Theorem_Paper.pdf`
- `projects/Multivariable_Taylor_Theorem_Presentation.pdf`

### Calculating Normal Probabilities without Tables

A graduate project based on Bagby's 1995 approximation method for standard normal probabilities.

Files:
- `projects/Calculating_Normal_Probabilities_Slides_8pp.pdf`
- `projects/Calculating_Normal_Probabilities_Slides_Full_24pp.pdf`
- `projects/Calculating_Normal_Probabilities_Poster.pdf`

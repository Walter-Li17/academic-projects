# Numerical code

- [math_kernels.py](math_kernels.py): subspace distances and related matrix comparisons.
- [retrieval_math.py](retrieval_math.py): weighted spectral representations and AP/mAP evaluation.
- [full_svd_library.py](full_svd_library.py): compact SVD and rank/energy selection utilities.
- [test_math_kernels.py](test_math_kernels.py) and [test_retrieval_math.py](test_retrieval_math.py): analytical checks and optional agreement checks against the original benchmark evaluator.

Requires Python and NumPy. See the [research overview](../README.md#run-the-numerical-checks) for the test command and optional data setup.

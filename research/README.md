# Research

## Image retrieval with DINO features and SVD

M.A. thesis in progress, supervised by Vahan Huroyan at Saint Louis University. Expected completion: Spring 2027.

I study image representations for retrieval, comparing frozen DINO features with matrix and SVD-based subspace methods. Current work includes a bounded method comparison on Revisited Oxford, numerical checks, and an interactive ranking demonstration. The next phase is to reproduce the supervised Grassmann pooling framework of Wei et al. (ECCV 2018).
